## 七、验收标准

> 以下所有条件满足，方可认为项目验收通过。

### 7.1 功能验收

- [ ] 所有 P0 功能正常可用（按功能列表逐项验证）
- [ ] 所有 P1 功能正常可用（如已纳入本期范围）
- [ ] 无 P0 级 Bug（导致核心功能不可用的 Bug）
- [ ] 无 P1 级 Bug（影响体验但有临时方案的 Bug）

### 7.2 技术验收

- [ ] 部署至生产环境，客户可通过域名访问
- [ ] HTTPS 已启用
- [ ] 性能指标达标（首屏 < 3s，API P99 < 500ms）

### 7.3 文档验收

- [ ] 已交付 README.md（包含启动指南）
- [ ] 已交付 API 文档（Swagger）
- [ ] 已交付运维手册

### 7.4 Bug 优先级定义

| 级别 | 定义 | 示例 |
|---|---|---|
| P0 | 核心功能不可用，或数据安全风险 | 无法登录、无法支付、数据泄露 |
| P1 | 功能有缺陷但有临时方案 | 排序错误、样式异常但功能可用 |
| P2 | 体验问题，不影响使用 | 文字错别字、动画卡顿 |
| P3 | 优化建议，非 Bug | 颜色不好看、想增加功能 |
